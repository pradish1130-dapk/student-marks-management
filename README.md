
# Student Marks Management System

My second Python programming project!

## About
A simple program to calculate student marks, total, average and grade.

## Features
- Enter student name
- Enter marks for five subjects
- Calculate total marks
- Calculate average
- Generate grades
- Validate marks between 0 and 100
- Handle invalid inputs

## Subjects

- Chemistry

## Technologies Used
- Python 2 / Python 3

## How to Run
1. Download Student_mark.py.
2. Open Python IDLE.
3. Open the downloaded file.
4. Press F5 to run.
